# Overgrind Wiki

Overgrind is a deterministic GUI feature-combination fuzzing and stress-test runner for Windows
desktop applications. It tests every ordered pair of main features with seeded random inputs.

**Status:** experimental v0.1 CLI with a Windows UI Automation adapter. The continuous standalone
GUI fuzzer described in the v0.2 specification is planned, not available.
